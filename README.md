# Xərc Dəftəri

Android üçün xərc izləyici. Yaradan: Məmmədov Vüsal.

Tətbiqin özü `app/src/main/assets/index.html` faylıdır; Android hissəsi onu ekranda göstərir.
Xərclər telefonun yaddaşında saxlanılır, internet tələb olunmur.

## APK almaq

**GitHub ilə (kompüterdə heç nə quraşdırmadan):**
1. github.com-da yeni repozitoriya yaradın.
2. Bu qovluqdakı bütün faylları (`.github` qovluğu daxil) ora yükləyin.
3. Actions bölməsində "APK yığ" işi bir neçə dəqiqəyə bitir.
4. Releases bölməsindən `XercDefteri.apk` faylını telefona endirib quraşdırın.

**Android Studio ilə:** qovluğu açın, sonra Build > Build APK(s).
